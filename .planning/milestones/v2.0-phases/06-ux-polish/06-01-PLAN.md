Create the directory `app/components/` and write `Header.tsx`. This is a new file — the directory does not exist yet.

Requirements from locked decisions:
- `'use client'` directive at the top (needed for the onClick signOut call)
- Accepts a single `title: string` prop
- Layout: flex row, justify-between, items-center
- Left side: h1 with the title prop, `text-2xl font-bold text-gray-900`
- Right side: a `<button>` with text "Logout" (plain text, not an icon — per locked decision)
- Button calls `signOut({ callbackUrl: '/auth/login' })` — CRITICAL: always pass callbackUrl to prevent redirect loop in production if NEXTAUTH_URL is misconfigured
- Outer wrapper matches the existing dashboard header style: `bg-white shadow-sm border-b border-gray-200`
- Inner div: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-4`

Use this exact implementation (from research):

```tsx
'use client';

import { signOut } from 'next-auth/react';

interface HeaderProps {
  title: string;
}

export default function Header({ title }: HeaderProps) {
  return (
    <header className="bg-white shadow-sm border-b border-gray-200">
      <div className="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-4">
        <div className="flex justify-between items-center">
          <h1 className="text-2xl font-bold text-gray-900">{title}</h1>
          <button
            onClick={() => signOut({ callbackUrl: '/auth/login' })}
            className="text-sm text-gray-600 hover:text-gray-900 transition-colors"
          >
            Logout
          </button>
        </div>
      </div>
    </header>
  );
}
```

No LogOut icon — locked decision specifies plain text "Logout" only.
