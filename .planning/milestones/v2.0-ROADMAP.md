**Completed:** 2026-07-18

### Phase 7: NHL Data Pipeline

**Goal**: A standalone Python script in /data-pipeline can ingest a complete NHL regular season of shot events into the nhl_raw.shot_events Postgres table with idempotency, rate-limiting, and a post-run row-count validation — with no coupling to the Next.js app

**Depends on**: Phase 6 (ordering only — pipeline is independent of app code)

**Requirements**: PIPE-01, PIPE-02, PIPE-03, PIPE-04

**Plans**: 3 plans

Plans:

- [x] 07-01-PLAN.md — Project scaffold + Wave 0 test stubs (pytest harness for all 4 PIPE requirements)
- [x] 07-02-PLAN.md — Core ingest.py: NHL API functions + DB writer functions (tests green)
- [x] 07-03-PLAN.md — main() CLI loop + progress/summary + integration smoke test verification

**Details:**

- TDD Wave 0: 12 test stubs across 4 files before any implementation
- `_psycopg_url()` helper strips Prisma-only `schema=` query param — Prisma accepts it, psycopg3 rejects it
- Sequential fetching (~1 req/s) with tenacity retry (3 attempts, exponential backoff) — no IP block risk
- Idempotent upsert: `ON CONFLICT (game_id, event_id) DO NOTHING`
- Writes to `nhl_raw` schema — no lock contention against live app tables
- Smoke test: Oct 4, 2024 → 19 games, 2,352 shots; full season run completed (89k+ shots); idempotency confirmed (0 new rows on re-run)

**Completed:** 2026-07-18

## Milestone Summary

**Key Decisions:**

- Zero new npm deps for Phase 6 — all UX primitives (loading.tsx, lucide-react, next-auth signOut) already installed
- signOut always passes `callbackUrl: '/auth/login'` — prevents production redirect loop if NEXTAUTH_URL misconfigured
- loading.tsx + `key={params.id}` for /games/[id] — loading.tsx does not re-trigger on same-segment navigation
- Pipeline writes to nhl_raw schema (not public) — prevents lock contention against live app tables
- Sequential pipeline fetching (~1 req/sec) — concurrent fetching risks NHL API IP block
- `INSERT_SQL` as module-level constant — test_db.py can patch it to redirect inserts to nhl_raw_test schema

**Known Gaps:**

- **UX-01 (partial):** Header.tsx with Logout not wired to `/games/add`, `/games/[id]/edit`, `/games/[id]/mental` — 3 form pages are middleware-protected but show no Logout button. Accepted as known gap; deferred to v2.1 or next maintenance pass.

- VERIFICATION.md `human_needed` status stale for Phase 7 — smoke test and idempotency confirmed during execution
